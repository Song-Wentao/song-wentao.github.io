# img/

Place all lab photos here.

Expected files (referenced in data/lab.js):
- pi.jpg          — PI headshot  (recommended: 400×400 px, square)
- members/        — subfolder for member photos (optional)
  - maya.jpg
  - james.jpg
  - yuki.jpg
  - sofia.jpg
  - daniel.jpg
  - aisha.jpg
  - tom.jpg

To use a photo, set the `photo` field in data/lab.js to the path
relative to the site root, e.g.:  "img/members/maya.jpg"

If a photo field is empty (""), the site will automatically
display the person's initials as a styled avatar.
